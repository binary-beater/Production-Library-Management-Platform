# Contributing to Production Library Management Platform

Thank you for contributing! Please follow this simple workflow to submit changes:

1. **Fork** the repository on GitHub.
2. **Branch**: Create a feature branch off `main` (e.g., `git checkout -b feature/cool-feature`).
3. **Commit**: Keep commits descriptive and ensure all formatting passes (`ruff check .` and `mypy .`).
4. **PR**: Open a Pull Request from your branch into `main` for review.
